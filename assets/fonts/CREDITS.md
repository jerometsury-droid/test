# Typography

The supplied video and public Wiki use **Unbounded** for headings and **Zen Kaku Gothic New** for body text. These font sources were obtained from the authoritative Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/unbounded — Copyright 2022 The Unbounded Project Authors.
- https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew — Copyright 2022 The Zen Kaku Gothic Project Authors.

Both are under SIL Open Font License 1.1; full licence texts are included beside this file. To reduce offline loading costs, the fonts have been subset to the characters used by this catalogue/interface using FontTools. Modified font families are renamed **Kyara Solo Display** and **Kyara Solo UI**. No generated character images or network font dependencies are involved.
